# Hodgkin–Huxley Neuron Simulation

## 0. Информация

Использован РК-4 с шагом 5e-6 в качестве идеала.
В случае передачи отрезка с большим значением длины - переход на идеал 1e-3.
Созданы 4 скрипта: run.sh, plot.sh, build.sh, diff.sh.




## 1. Compile

Для запуска программы необходимо скомпилировать: ./build.sh




## 2. run.sh - запуск

Скрипт run.sh позволяет запускать отдельные методы или смотреть на ошибку аппроксимации.
Существует два режима использования данной программы (0 и 1):

run.sh 
1. - method (dp, rk4, mid) - выбор численного метода решения.
2. - mode (0 / 1) - режим работы программы:
  0 - обычный расчёт (вывод траектории)
  1 - режим анализа точности (calculus)
3. - Iext - внешний ток (в модели используется со знаком минус)
4. - t_end - конечное время моделирования.
5. - h - шаг интегрирования (для rk4 и mid в режиме 0), начальный шаг для dp в обоих режимах.
6. - tol - допустимая погрешность (используется в calculus режиме)
7. - Rtol - локальная погрешность для метода Дормана-Принса.


Пример запуска: ./run.sh rk4 0 10 10 0.01 1e-3 1e-10





## 3. Построение графиков

Используя скрипт plot.sh можно строить графики.
Как единичного метода, так и нескольких с разными параметрами.



















## 4. Построение графиков
Используя скрипт diff.sh можно строить графики разности решения двух методов.
Предварительно используем run.sh для двух методов, которые хотим лицезреть.
Необходим тончайший баланс, иначе возможны дефекты.
Для предотращения ошибок желательно использовать среднее-высокий шаг и неглубокую толеранс для dp.
Пример: diff.sh rk4.txt dp.txt

## 1. Общие сведения

Реализация выполнена на языке программирования C.



## 2. Теоретическая основа

В основе модели лежит описание полной плотности мембранного тока:
Натриевый ток (INa),
Калиевый ток (IK),
Ток утечки (Il).

Система уравнений включает четыре переменные состояния:
Мембранный потенциал V,
Параметры активации и инактивации каналов: m, h, n.

Модель воспроизводит полный цикл потенциала действия:
1. потенциал покоя,
2. деполяризация,
3. реполяризация,
4. рефрактерный период.



## 3. Численный метод

Для решения системы обыкновенных дифференциальных уравнений используется численный метод интегрирования, реализованный в модуле `methods.c`.



## 4. Сборка проекта

Сборка осуществляется с помощью Makefile:

```bash
make

Добавлены скрипты:
Для упрощения запуска, анализа и демонстрации модельно-исследовательской работы были созданы четыре SH-файла:
build.sh,		run.sh,	test_all.sh,		plot.sh
При запуске:
Первый параметр – метод
Второй параметр – шаг (для режима calculus является tol)
Третий параметр – ток (положительное число)
Четвертое число – мод (по умолчанию 0 – вывод решения системы ОДУ)
Примеры использования:
./build.sh                    # пересобрать проект
./run.sh dp                   # Dormand-Prince (обычный режим)
./run.sh rk4 0.001 15        # RK4 с другим током
./run.sh dp 0.04 10 1        # запустить calculus-режим
./test_all.sh                 # полный тест режимов
./plot.sh                     # построить график (автоматически стоит DP)
